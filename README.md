# Dental Clarity

A full-stack demo built from a Node.js authentication starter project. Dental Clarity helps dental professionals explain diagnoses to patients in simpler words.

## Features so far
- Signup and login for dental professionals
- Add and view demo patients
- Choose gingivitis, periodontal disease, or dental caries
- English and Spanish diagnosis explanations
- Update language and diagnosis, or delete a demo patient
- View a basic visit summary

## Still working on
- Educational images
- Custom treatment plans and aftercare
- Sending visit summaries by email
- Better patient profile editing

## Run locally
1. Install Node.js and MongoDB.
2. In the project folder run `npm install`.
3. Start MongoDB locally or set `MONGODB_URI` to your own database connection string.
4. Run `npm start`.
5. Open http://localhost:8080.
